# Data Directory

Place MedDRA data files here:

- **meddra_terms.jsonl.gz** — MedDRA terms (18K+ entries)
- **meddra_vectors.npz** — Semantic embeddings
- **Important-medical-event-29_1.xlsx** — IME list (7,843 terms)

These files are NOT included in the repository due to size.
Download them from your MedDRA source and place them here.
